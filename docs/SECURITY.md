# CollegeHelper 보안 설계

## 보호 대상

- Canvas 개인 액세스 토큰
- LTI 세션 쿠키와 일시적인 다운로드 URL
- 수강 과목, 과제, 제출 상태와 공지 본문
- 강의자료 원문
- 홈서버 네트워크와 파일시스템

## 기본 원칙

1. **최소 권한:** Canvas API는 GET만 사용합니다.
2. **최소 반환:** 질문에 필요한 정규화 필드만 MCP 응답에 포함합니다.
3. **최소 저장:** 실제 API 응답과 원본 PDF를 영구 저장하지 않습니다.
4. **비밀 분리:** 토큰과 실제 사용자 응답을 소스 코드와 Git에서 분리합니다.
5. **외부 콘텐츠 불신:** 공지, 설명과 강의자료 본문을 신뢰되지 않은 입력으로 표시합니다.

## 인증정보 관리

- `CANVAS_ACCESS_TOKEN`은 `.env`에서만 읽으며 Git에서 제외합니다.
- `configure-env.sh`는 토큰을 숨김 입력으로 받아 권한 `600`의 파일을 생성합니다.
- Authorization 헤더와 토큰 값은 오류, 감사 보고서와 로그에 기록하지 않습니다.
- OpenAI Runtime API key도 별도의 권한 `600` 시크릿 파일로 관리합니다.
- 토큰을 URL 쿼리 파라미터, 명령 인자 또는 채팅 메시지로 전달하지 않습니다.

## 네트워크 통제

### Canvas API

- 설정한 Canvas 원본 호스트만 허용합니다.
- `/api/v1/` 경로만 인증 요청 대상으로 사용합니다.
- Canvas 데이터 요청은 GET으로 고정합니다.
- 페이지네이션 리다이렉트도 동일한 호스트와 API 경로인지 확인합니다.

### 외부 LTI 자료실

- Canvas 공식 sessionless launch로만 진입합니다.
- 사이트가 요구하는 로그인 핸드셰이크 이외의 비-GET 요청을 차단합니다.
- 진도, 완료 상태와 사용자 행동 기록을 변경하는 요청을 허용하지 않습니다.
- 브라우저 감사 시 HAR, 응답 본문과 쿠키를 저장하지 않습니다.

### 홈서버

- MCP 포트는 `127.0.0.1`에만 바인딩합니다.
- ChatGPT 연결은 Secure MCP Tunnel을 사용합니다.
- 컨테이너는 읽기 전용 루트 파일시스템과 `no-new-privileges`로 실행합니다.

## 데이터 저장

| 데이터 | 저장 정책 |
|---|---|
| Canvas 토큰 | 홈서버 `.env`, 권한 `600` |
| Runtime API key | 별도 로컬 시크릿 파일, 권한 `600` |
| Canvas 원본 응답 | 저장하지 않음 |
| LTI 쿠키·서명 URL | 저장하지 않음 |
| 원본 PDF | 텍스트 추출 직후 삭제 |
| 추출 텍스트 | Docker 전용 볼륨에 캐시 |
| 감사 결과 | 상태, 필드명과 항목 수만 비식별 저장 |
| 테스트 fixture | 합성 데이터만 사용 |

## MCP 응답 보호

- 성적, 점수, 이메일, 로그인 ID와 액세스 토큰을 결과에서 제외합니다.
- 알려지지 않은 내부 오류는 일반화된 메시지로 변환합니다.
- Canvas 설명, 공지와 강의자료 원문은 신뢰되지 않은 외부 콘텐츠로 취급합니다.
- 도구에는 `readOnlyHint`, `destructiveHint: false`, `idempotentHint: true`를 지정합니다.

## 공개 저장소 점검 항목

커밋 또는 배포 전에 다음 내용을 확인합니다.

- `.env`와 시크릿 파일이 Git 추적 대상이 아닌지 확인
- 토큰 형식, Authorization 헤더와 개인 서버 주소 검색
- 실제 과목명, 과제명, 사용자 ID와 서명 URL 검색
- 실행 화면에서 과목·과제·날짜·제출 상태 블러 처리 확인
- 테스트 fixture와 스냅샷에 실제 LMS 응답이 없는지 확인
- 타입 검사, 린트, 테스트와 빌드 실행

## 의도적으로 지원하지 않는 기능

- 과제·퀴즈 답안 제출
- 게시물, 일정과 파일 작성 또는 수정
- 성적과 점수 조회
- 다중 사용자 토큰 보관
- 임의 URL 요청과 홈서버 셸·파일 접근
